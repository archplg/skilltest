Метод и границы

Как считалось

  • Инструмент: SkillTest, guard из 53 правил RU/EN плюс файловые проверки и модель контекста.
  • Серьёзность откалибрована на этих же корпусах: три полных прохода по GitHub-каталогам (87 → 30 → 0 ложных блокировок).
  • Блокировка = хотя бы одна critical-находка, не понижённая контекстом. Фикстуры сканеров исключены.
  • Хеш-подобные строки, ключи, e-mail и токены Telegram в уликах замаскированы.

Что видит и чего не видит

  • Видит текст: инструкции, скрипты, конфиги, HTML-комментарии, невидимые символы.
  • Не видит: содержимое URL, который скачивает установщик; живость ключей; поведение при выполнении.
  • Скиллы про безопасность содержат ровно те строки, которые ищутся; их markdown понижается на ступень, скрипты нет.
  • Сравнение с собственным сканером ClawHub: их «suspicious» ≈ наш medium (объём полномочий), блокировок нет ни у кого.
