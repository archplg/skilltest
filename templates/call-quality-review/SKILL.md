# Разбор разговора контакт-центра

Сверяет три свидетельства одного обращения: что прозвучало в разговоре, что записано в карточке CRM и что требует регламент. Выдаёт перечень отклонений с цитатами.

## Когда применять

Применяйте для выборочного контроля качества: один разговор за один запуск, с расшифровкой и карточкой обращения на руках.

Не применяйте для оценки сотрудника, для сравнения операторов между собой и для решений о премии или увольнении. Скилл оценивает разговор, а не человека, и об этом надо помнить: один разговор не характеризует оператора.

## Что нужно на входе

1. **Расшифровка разговора**: реплики с указанием, кто говорит, и временными метками. Аудио скилл не слушает: нужна текстовая расшифровка.
2. **Карточка обращения из CRM**: тема, что зафиксировано, какое решение записано, статус, время обработки.
3. **Чек-лист качества**: пункты регламента с весами, например приветствие, идентификация клиента, проверка данных, предложение решения, фиксация в системе, завершение.

Если чек-листа нет, не выдумывайте свой: попросите его. Оценка по несуществующему регламенту бесполезна и несправедлива.

## Как сопоставлять

Каждый пункт чек-листа проверяйте **по цитате из расшифровки**. Пункт считается выполненным, только если есть конкретная реплика. Если реплики нет, пункт не выполнен, даже если по смыслу оператор действовал верно: контроль качества проверяет наблюдаемое поведение.

Карточку CRM сравнивайте с содержанием разговора: совпадает ли тема, отражено ли обещание, данное клиенту, совпадает ли статус с тем, чем разговор закончился.

## Шаги

1. Прочитайте расшифровку, карточку и чек-лист.
2. Пройдите чек-лист по порядку, для каждого пункта найдите цитату или отметьте отсутствие.
3. Сравните карточку с разговором: тема, обещание, решение, статус.
4. Отметьте отклонения из таблицы ниже.
5. Посчитайте итог по весам чек-листа.
6. Соберите отчёт: сначала что сделано хорошо, затем отклонения с цитатами.

## Какие отклонения искать

| Тип | Признак | Что с этим делать |
|---|---|---|
| Пункт регламента пропущен | Нет реплики, подтверждающей выполнение | Обучение: показать формулировку |
| Обещание не зафиксировано | В разговоре обещано, в карточке нет | Немедленно: дописать в карточку |
| Тема карточки не совпадает | Клиент звонил о другом | Аналитика: тема искажает отчётность |
| Статус не соответствует | Разговор не завершил вопрос, статус «решено» | Руководитель: вернуть в работу |
| Персональные данные без проверки | Данные названы до идентификации | Безопасность: серьёзное нарушение |
| Клиент прерван | Реплика оператора поверх реплики клиента более трёх раз | Обучение: техника слушания |

## Если что-то пошло не так

- Расшифровка без разделения ролей: скажите об этом, оценку по чек-листу не давайте, она будет недостоверной.
- Карточка пустая: отметьте это как главное отклонение и продолжите разбор разговора.
- В расшифровке есть номер карты или паспортные данные: не выносите их в отчёт, замените на «данные названы».
- Разговор короче трёх реплик: скажите, что разбирать нечего.

## Результат

Готово, когда выдан разбор одного разговора. Формат:

```
РАЗБОР: обращение 884213 · 11.09.2026 · длительность 4:12

Выполнено: 6 пунктов из 9. Итог по весам: 72 из 100.

Что сделано хорошо
— Приветствие по регламенту: «Добрый день, компания N, меня зовут…» (00:03)
— Решение предложено сразу: «Могу оформить замену сегодня» (02:11)

Отклонения
1. Идентификация клиента пропущена. Оператор назвал номер заказа до проверки личности (00:41). Тип: персональные данные без проверки. Серьёзно.
2. Обещание не зафиксировано. В разговоре: «перезвоню завтра до обеда» (03:50), в карточке этого нет.
3. Статус «решено», хотя вопрос отложен до звонка.
```

Если отклонений нет, напишите это и приведите цитаты по ключевым пунктам: разбор без доказательств бесполезен.

## Чего этот скилл не делает

Не выставляет оценку оператору как сотруднику, не меняет карточку в CRM, не пишет клиенту и не инициирует дисциплинарных мер.
